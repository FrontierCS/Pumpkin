Remove what ended runs left.

For each run whose driver has ended, `reap` deletes the sandboxes that remain on each provider it
ran on. It removes the run's socket directories and records a lost run as failed. It leaves a live
run to its driver. If a run can't be reaped, `reap` says why and reaps the others. It prints the ids
of the runs it cleaned.

With `[controller]` in the configuration and no `--runs`, `reap` reaps the controller's runs that
this build made.

Usage: pumpkin reap [OPTIONS]

Options:
      --runs <dir>
          The directory of the runs to reap (default: `runs` in the repository's `.pumpkin`)

  -h, --help
          Print help

Examples:
  pumpkin reap
  pumpkin reap --runs runs

Exit status:
  0  Nothing that the runs left remains.
  3  `reap` can't reach a provider of a run, which it names, and nothing else
     failed. What the run left there may remain. The provider's Docker context
     may be gone, or the configuration may no longer name the provider.
